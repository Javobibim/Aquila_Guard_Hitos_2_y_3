Comprueba tu instalación

Esperando el aviso de la extensión…

  1. Usa Aquila Guard 0.6.4 en un PC para probar el aviso con el semáforo.
  2. Abre el águila, pulsa Activar mis avisos y acepta el acceso a sitios.
  3. Recarga esta pestaña. Espera unos segundos.
  4. La tarjeta debe decir Precaución: publicidad invasiva e identificar esta página como demostración.

No se marca esta web como fraudulenta en ninguna lista. La prueba utiliza el mismo conteo de espacios visibles que una página externa.

Esta prueba requiere la extensión de PC. En Android puedes revisar enlaces desde la app web o instalar la aplicación Android.
